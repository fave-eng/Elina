# Elina English Space — новая версия

Это полноценная версия на той же архитектуре, что и сайт Кристины.

## Что изменено

- Все домашние задания открываются одной страницей: `lesson.html?id=lesson-1`, `lesson-2`, `lesson-3`.
- Содержимое трёх старых страниц перенесено в `data/lessons/*.json`.
- Файлов `lesson1.html`, `lesson2.html`, `lesson3.html` в новой версии нет.
- Ответы сохраняются как черновик при вводе, после проверки сохраняются баллы, после отправки — статус `submitted`.
- Используется общий Supabase-проект и общие таблицы: `homework_progress`, `vocabulary_progress`, `vocabulary_topic_progress`, `grammar_progress`.
- Для Элины всегда используется `student_id = elina`.
- Старые результаты из браузера (`elina_hw1_score`, `elina_hw2_score`, `elina_hw3_score`) автоматически импортируются при первом открытии на прежнем устройстве.
- Прямой Telegram API отключён. В архиве нет Telegram-токена.

## Перед публикацией

1. В общем Supabase откройте SQL Editor.
2. Выполните файл `supabase/01-import-existing-progress.sql`.
3. Убедитесь, что запрос вернул три строки: `5/34`, `41/49`, `29/33`. Для третьего задания точная дата на скриншоте не видна, поэтому SQL запишет время переноса.
4. Загрузите содержимое этой папки в репозиторий сайта Элины.
5. Не переносите старые файлы `lesson1.html`, `lesson2.html`, `lesson3.html` и старые страницы словаря.

## Проверка после публикации

Откройте:

- `homework.html` — должны быть три задания и сохранённые результаты;
- `lesson.html?id=lesson-3` — должен восстановиться результат `29/33` из общей базы;
- измените тестовый ответ, нажмите Check answers, затем Submit to teacher;
- в Supabase отфильтруйте `homework_progress` по `student_id = elina` и проверьте `updated_at`.

Если Supabase временно недоступен, сайт сохраняет данные на устройстве и показывает сообщение об ошибке синхронизации. При следующем открытии он снова пытается синхронизировать данные.
